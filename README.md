# orekhprom — макеты страниц

Статичные макеты новых страниц orekhprom.ru в дизайне обновлённой главной.
Главная (`index.html`) — список всех страниц; между страницами можно переключаться панелью над шапкой.

- `assets/site.css`, `assets/site.js` — общая дизайн-система: шапка, подвал, попапы, переключатель страниц
- `assets/category.js` — шаблон категории B2B (орехи, пасты, ингредиенты, начинки)
- `assets/em/` — фото и видео страницы «Пасты и начинки ЕМ!»

`assets/site.js` собирается из `assets/site.src.js` подстановкой логотипа из `assets/logo-inline.txt`.
Остальные изображения подгружаются с orekhprom.ru.
